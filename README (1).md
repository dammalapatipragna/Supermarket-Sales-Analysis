# Supermarket Sales Data Analysis

## Project Description
This project performs an end-to-end Exploratory Data Analysis (EDA) on supermarket transactional sales data containing 500 records. It uncovers business trends, sales performance across categories/branches, customer payment behaviors, and purchasing correlations.

## Technologies Used
- **Language:** Python 3
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Platform:** Google Colab / Jupyter Notebook

## Setup and Run Instructions
1. Ensure you have Python installed.
2. Install required libraries using the requirements file:
   ```bash
   pip install -r requirements.txt
   ```
3. Place the dataset `SUPER MARKET DATA - supermarket_sales_500_rows.csv` in your working directory.
4. Run the Jupyter Notebook to generate analysis plots and business summaries.

## Key Insights Summary
